# E-commerce Discount Intelligence

A learning project built step by step by Khoi.

Question: Should a retailer send this shopper a discount, or would they buy anyway?

## Current status

The raw Synerise Parquet files are downloaded in data/raw/. The Python environment and dependencies are installed. Analysis has not started in this learning version. No models or results are included.

## First step

Inspect a small sample in Excel to understand the columns and what one row means. Keep the original Parquet files unchanged; they are too large to load into a worksheet in full.

## Local folders

- data/raw/: original data, excluded from Git
- data/processed/: future work, excluded from Git
- notebooks/: your future notebooks
- sql/: your future queries
- reports/: your future findings

Dataset source: https://recsys.synerise.com/data-set. Review and follow the publisher's license. RecSys 2025 is the release/challenge label; the downloaded events are from 2022.
